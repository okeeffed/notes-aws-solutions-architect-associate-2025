# Amazon Managed Workflows for Apache Airflow (MWAA) #card

Amazon MWAA is a **managed service** that helps you **orchestrate and automate** data workflows using Apache Airflow.

---

## MWAA Workflows #card

- Designed as **Directed Acyclic Graphs (DAGs)** using Python
- Supports **sequential and parallel execution** of tasks

---

## MWAA Use Cases #card

- **Complex Data Workflows** – Handles complex data processing tasks
- **ETL Jobs** – Coordinates **Extract, Transform, Load (ETL)** processes
- **Machine Learning** – Prepares datasets for ML models

---

## MWAA Key Features #card

- **Deployment** – Easy setup and operation
- **Scaling** – Auto-scales to match workload demands
- **Security** – Built-in data protection measures
- **Monitoring** – Comprehensive tracking of workflows
- **Cost-Effectiveness** – Reduces operational costs due to managed nature

---

## MWAA Security #card

- **Network Isolation** – Operates within **Amazon VPC**
- **Data Encryption** – Uses **AWS KMS** for automatic encryption

---

## MWAA Pricing #card

- **Environment Pricing** – Billed hourly based on **environment size**
- **Additional Worker Instances** – Billed hourly based on **task load**
- **Additional Scheduler Instances** – Billed hourly based on **availability**
- **Database Storage** – Billed per **GB-month** for consumed storage
